# Elevare - Multi-User Portfolio Platform

Built with Flutter & Dart

## Quick Start

```bash
# Start with Docker
docker-compose up -d

# Or run locally
cd backend && dart pub get && dart run bin/server.dart
cd frontend && flutter pub get && flutter run -d chrome
```

## Features
- 3D Landing Page
- Portfolio Builder
- Template Marketplace
- Analytics Dashboard
- JWT Authentication
